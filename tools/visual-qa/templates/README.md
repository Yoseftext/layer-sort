# Reviewed visual templates

Place only small, owner-reviewed PNG crops from the exact intended game build here.
The filename must use lowercase letters, digits, underscore or hyphen and no
personal information. Do not automatically create or replace a reference from
the latest screenshot. Record the source commit, APK hash, locale, orientation
and intended screen in the corresponding review.

A template match is a candidate visual clue, not a proof of game state, a
physical touch test, or permission to click. Animations, scaling and similar
objects can create false matches; review the actual screenshot and corroborate
with game-state/log evidence. No production game template is included yet.
